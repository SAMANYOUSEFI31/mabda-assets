# mabda-assets
تصویرهای سنگین مخزن mabda (`docs/screens/**`) با همان مسیرها. توضیح: `docs/screens/README.md` در mabda.

قرار حجم: PNGها پیش از کامیت به ۲۵۶ رنگ (PNG8، بی‌dither) فشرده می‌شوند (`convert in.png -dither None -colors 256 PNG8:out.png`)؛ برای اسکرین‌شات رابط تفاوتی دیده نمی‌شود و حجم حدود ۶۰٪ کم می‌شود. ویدئو کامیت نمی‌شود؛ به‌جایش نوار فریم.
