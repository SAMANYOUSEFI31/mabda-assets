# حرکت (mabda §۵۷)

فریم‌هایی که هر ۴۰ میلی‌ثانیه از ویدئوی واقعی برنامه برداشته شده‌اند. در هر تصویر، ردیف بالا «قبل» (main) و ردیف پایین «بعد» است.

- `page-switch-<عرض>-<روشن|تیره>.png`: رفتن از «خانه» به «حقیقت». قبل: صفحه در یک فریم عوض می‌شود و تازه محو می‌آید. بعد: «محو از میان» (اول قبلی می‌رود، بعد تازه می‌آید)؛ نوارها ثابت می‌مانند.
- `sidebar-sections-1280.png`: بخش‌های «حقیقت» در نوار کناری. قبل: «خروجی‌ها» یک‌باره پایین می‌پرد. بعد: قد بخش نرم باز می‌شود.
- `segmented-glide-1280-after.png`: کلید برآمدهٔ «ساختار · نمای کلی · سند · جدول» از «ساختار» به «سند» سُر می‌خورد.
