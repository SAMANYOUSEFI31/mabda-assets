- `canvas-zoom/`: §۴۸ج، ۲.۵× با خط کلفت (قبل)، ۱.۶× و کمینه نزدیک «همه در قاب» (انتخاب)
- `canvas-rows/`: §۴۸د، باز و جمع کردن زیربخش‌ها، دید سر جایش
- `rail-title/`: §۴۸ز، سرتیتر نوار باریک فقط با نام فضا
- `proposal-reason/`: §۴۸ص، «افزودن دلیل» با برچسب؛ `context-waiting-*` و `canvas-*` برای §۴۸ف
- `tour/`: §۴۸ی، پنج قدم گشت، ۱۲۸۰، ۳۹۰ و تیره
- `onboarding/`: §۴۸ک، ورود آزمون‌گر: دعوت، «فضای خودت را بساز»، خانهٔ خالی، فهرست فضا با نمونه در آخر، خط فضای نمونه
- `quick-capture/`: §۴۸م، ساخت فضا، گشت، اولین فکر و اعلان (۱۲۸۰ و ۳۹۰)
- `w1920/`: §۴۸، بررسی ۱۹۲۰
